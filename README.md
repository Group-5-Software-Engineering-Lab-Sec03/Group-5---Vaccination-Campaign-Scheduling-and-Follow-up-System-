Vaccination Campaign Scheduling and Follow-up System

As part of our Software Engineering coursework, our team is developing and applying structured requirements analysis, version control, and iterative development practices. Vaccination Scheduling is a vaccination campaign scheduling and follow-up system for clinics. Patients book dose appointments, staff track records, and the system flags missed follow-up doses to boost completion rates.

Repository Structure
-Team/: team member info, skills, contact details, CVs
-Project/: project title, description, scope, process model, risk register, stakeholders, feasibility study
-Documents/: supporting documentation
-Source_Code/: application source code
